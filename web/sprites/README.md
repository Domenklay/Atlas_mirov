# Атлас живых миров — модульный стартовый пакет

6 настоящих независимых векторных спрайтов **только туловищ** без фона, головы, рук, ног и хвостов. Единый холст 620×780, вид спереди. `manifest_v080.json` содержит единые координаты крепления. Файлы не являются разрезанными изображениями коллажа.

Каждый SVG прозрачен; графика и её геометрия создана программно. Для последующих наборов требуются отдельные головы, руки, ноги, хвосты и крылья на том же координатном холсте. Сменные части в демоверсии собирает `web/modular_editor_v080.js`. Текущая версия представляет технический прототип, а не финальный художественный рендер.
