# Атлас живых миров

Конструктор фантастических существ: анатомия, экология, эволюция и личный каталог видов.

**Текущая версия:** 0.7.9 — офлайн-прототип на русском языке.

## Возможности
- **v0.7.9 — согласование анатомии в трёх видах:** общий набор размеров для фронтальной, боковой и задней проекции. Векторный движок реагирует на 0, 2 или 4 руки и ноги (если не выбран рыбий хвост), одиночный рог, пару рогов или ветвистые рога; улучшены глаза в профиль и рисунок чешуи, древесной кожи и пятен. Ширина туловища в боковой проекции меняется при настройке плеч, талии и телосложения.
- Конечности теперь рисуются общими кривыми с мягким локтевым и коленным переходом вместо отдельных круглых суставов. Сохраняются редактор, цвета, генетика, три ракурса и экспорт JSON/PNG/SVG. Графика остаётся программной SVG без растровых персонажей.
- Технические ограничения: четыре ноги при взгляде сбоку частично перекрываются, а для некоторых гибридных анатомий нужна дальнейшая ручная доводка. Трёхмерной модели и анимации нет. Отладочная APK-подпись всё ещё непостоянная: для переноса коллекции используйте JSON.

- **v0.7.8 — векторные существа во всех трёх ракурсах:** для модульного редактора впервые добавлены отдельные программные SVG-проекции спереди, сбоку и сзади. Боковая и задняя проекции строятся из головы, шеи, корпуса, рук, ног или рыбьего хвоста, крыльев и деталей спины. Они больше не подменяются прежним упрощённым рисунком.
- Шесть типов туловища получили разные пропорции: массивное драконье, лёгкое фейское, водное, инопланетное, гуманоидное и растительное. Регуляторы ширины, роста, длины рук, окрас, поза и выбор конечностей продолжают влиять на построение во всех ракурсах. Рептильи, змеевидные и перьевые хвосты доступны и в боковой/задней проекции.
- Исправлена подгонка SVG к рамке на компьютерах и телефонах, чтобы высокие фигуры и хвосты не обрезались. Ни один ракурс не использует готовые картинки. Экспорт PNG/SVG использует текущее изображение, JSON сохраняет вид и настройки.
- Графика остаётся стилизованной процедурной иллюстрацией: нет полноценной анимации и физического моделирования опорно-двигательного аппарата. Приложение собирается как отдельный debug APK и не устанавливается поверх прежних версий без переноса JSON.

- **v0.7.7 — улучшенная программная графика:** форма черепа, скул, подбородка и губ заново строится кривыми Безье. Добавлены радужки с бликами, анатомические тени, жаберные пластины русалок, гребни драконидов, узоры инопланетян, растительные прожилки и фейские световые точки.
- **Суставы и чешуя:** смягчены круглые локти и переходы предплечий; чешуя на теле и рыбьем хвосте стала многослойной. Положение рук теперь можно выбирать: естественная поза, расправленные руки, плавание. Все новые эффекты — SVG-код, готовые картинки/растровые спрайты не используются.
- Новая прорисовка действует в модульном режиме спереди. Классический рисунок и старые боковой/задний виды, JSON-каталог, генетика и экспорт PNG/SVG оставлены. Выбранная поза сохраняется вместе с существом.
- Приложение пока является игровым стилизованным редактором, а не фотореалистичной анатомической симуляцией. Android APK имеет отдельный debug package ID, поэтому коллекцию переносить через JSON.

- **v0.7.6 — возвращена программная отрисовка существ:** художественный WebP-набор русалки выключен в приложении и полностью исключён из APK. Все изменяемые персонажи рисуются кодом через SVG: тело, голова, руки с пальцами, ноги, рыбьи хвосты, чешуя, плавники, рога, крылья и узоры. В новом модульном режиме геометрия частей формируется заново при изменении ползунков.
- Векторные туловища и цвета шести основных форм, смена головы/рук/нижней части тела, генетика, экспорт PNG/SVG/JSON и каталог сохранены. Старые v0.7.5 художественные русалки автоматически переводятся в модульные векторные формы, насколько это возможно без исходных WebP-деталей. Исправления сохранения из v0.7.4 не удалены.
- Пока новый векторный режим поддерживает вид спереди, а сбоку и сзади использует старую процедурную систему. Для управления цветом выбери «Использовать выбранную окраску существа». Отдельная Android debug-сборка устанавливается рядом с предыдущей из-за временной подписи.

- **v0.7.5 — первый художественный сборный комплект русалки:** девять независимых прозрачных WebP-деталей, созданных на основе художественных 2D-иллюстраций: два туловища, две головы, два хвоста, плечо, предплечье и кисть. Полный архив также доступен пользователю с исходными PNG.
- В редакторе появился дополнительный режим «Художественный набор · Русалка». Туловище, голова и хвост выбираются независимо, левая и правая руки собираются из отдельных сегментов и отражаются. Контрольные суставы закрываются небольшими декоративными элементами. Предыдущий генератор и старые шесть схематичных туловищ остаются доступными.
- Все девять WebP включаются в автономный APK в виде встроенных data URI, а файлы и `manifest.json` хранятся отдельно в `web/sprites/mermaid_v075/`. Выбор художественных деталей записывается в каталог, JSON и черновик.
- **Ограничения:** художественные спрайты пока экспериментальны; на локтях, кистях и границе хвоста могут быть заметны швы. Только фронтальный вид. Параметры анатомии изменяют масштаб готовых слоёв, но не отдельные внутренние черты рисунка. Смешивание художественных деталей в генетике, сложные позы и ракурсы входят в следующие этапы.

- **v0.7.4 — надёжная основа модульного конструктора:** исправлен сценарий, когда модульные поля в сохранённых каталогах терялись в ходе ранней очистки записей предыдущими версиями. При запуске оригинальный каталог копируется в память до инициализации старых модулей, затем проводится безопасное восстановление из исходных данных. Сохранённые детали теперь можно заново открыть из коллекции; черновик модульной сборки хранится отдельно.
- Координаты соединений теперь читаются из `web/sprites/manifest_v080.json` и применяются к отдельным SVG-группам головы, рук, туловища и нижней части тела. Изменение ползунков размера, ширины головы, плеч/талии, длины рук и комплекции влияет на модульную модель. Появился включаемый режим подсветки точек крепления.
- Опциональная окраска туловища в основной и дополнительный цвет сохраняет орнаменты. Редактор и генетика предыдущих версий остаются. В Android манифест и исходные SVG встроены локально; интернет не нужен.
- **Ограничения:** поддерживается только вид спереди в модульном режиме; художественные головы/руки/ноги ещё процедурные, но отделены в самостоятельные слои. Сложные формы, нестандартные крылья и произвольное число ног пока в модульном режиме не реализованы.

- **v0.7.3 — первый технический модульный 2D-конструктор.** Шесть настоящих независимых SVG-туловищ: гуманоидное, водное, фейское, драконье, инопланетное, растительное. Без фона, головы и конечностей; все на одном полотне 620×780. У всех одинаковые координаты шеи, плеч, таза, крыльев и хвоста, описанные в `web/sprites/manifest_v080.json`.
- Новый переключаемый режим «Модульный 2D-конструктор» в редакторе: можно независимо менять **6 туловищ, 3 головы, 3 типа рук/кистей, 2 типа нижней части тела**, всего 108 потенциальных комбинаций. Слои соединяются по фиксированным якорям и составляют одну фигуру. Параметры сборки записываются в JSON. Предыдущий процедурный генератор и генетика сохранены.
- **Ограничения прототипа:** новые наборные спрайты доступны только в виде спереди. При виде сбоку/сзади автоматически отображается прежняя векторная модель. Детальные SVG-процедуры для голов/рук/ног будут заменяться отдельными готовыми высококачественными спрайтами по мере подготовки библиотеки. Фоновая прозрачность подтверждается SVG.
- APK содержит отдельные SVG-файлы торсов и манифест плюс встраивает их непосредственно в автономный HTML (без интернет-запросов). Отдельный package ID для установки рядом с прежней debug-версией, импорт коллекции через JSON.

- **v0.7.2 — анатомические силуэты:** отдельная процедура прорисовки реальных форм головы (включая выразительную морду драконида, заострённый подбородок феи, череп инопланетянина), шеи и различного по ширине корпуса. Суставные руки, кисти с пальцами или когтями, двусоставные ноги, копыта/ласты, крупные крылья со строением перепонок и перьев, хвосты с деталями. Формы реагируют на исходную расу, параметры анатомии и набор органов. Доступны передняя, боковая и задняя проекции.
- Сцены, графические детали v0.7.1, пользовательские виды, сохранения и генетика v0.7 продолжают работать; процедура `web/anatomy_shapes_v072.js` автоматически встраивается в офлайн-APK.

Добавлены обычная и адаптивная иконки Android, а также фирменный значок в шапке Android-приложения. Базовые механики и интерфейс v0.5.4 не менялись.

## Перенос коллекции из v0.1 и v0.2
В первоначальной версии 0.1.1 использовалась временная debug-подпись, поэтому APK новой сборки нельзя безопасно ставить поверх неё. Версии 0.2–0.5.1 используют разные package ID (`com.atlas.mirov.v2`, `.v3`, `.v4`, `.v5`, `.v51`), чтобы debug-сборки с временной подписью могли быть установлены параллельно. В новой версии импортируйте JSON-каталог из старой перед её удалением. Откройте старую версию, выберите **Экспорт каталога**, затем в новой версии выберите **Импорт JSON** и укажите полученный файл. Старые записи дополняются начальными настройками новых анатомических полей и подвидов. Сохранение данных между будущими debug-APK с временными подписями пока не гарантировано; перед переустановкой всегда экспортируйте коллекцию.

## Android APK
Workflow **Android APK** в разделе [Actions](../../actions) собирает debug APK для Android. Скачайте ZIP-артефакт `atlas-mirov-debug-apk` из успешного запуска и установите APK на телефон. Это отладочная сборка; для публикации в Google Play потребуется release-подпись.

## Запуск в браузере
После распаковки `web/index.html` файл открывается в браузере и работает офлайн. Приложение не передаёт коллекцию существ на сервер.

## Ограничения
Изображения существ пока стилизованные векторные иллюстрации, а не фотореалистичный или 3D-редактор. Биологическая модель игровая и не претендует на научную точность.

## Структура проекта
- `web/index.html` — автономное браузерное приложение;
- `android/` — минимальная Android-оболочка с WebView и системным экспортом файлов;
- `.github/workflows/android.yml` — сборка установочного APK.

### Подпись APK
Автоматическая сборка GitHub Actions сейчас использует **отладочную подпись**, которая может меняться от сборки к сборке. Обновление поверх другой debug-сборки может не установиться; резервное копирование через JSON обязательно. Для безопасного обновления одним APK без смены package ID нужна постоянная приватная подпись release в GitHub Actions Secrets. Приватный ключ **не следует хранить в публичном репозитории**.

### Данные
Веб-версия и Android-версия используют разные локальные хранилища. Используйте экспорт JSON для переноса каталога между ними.
