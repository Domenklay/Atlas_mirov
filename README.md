# Атлас живых миров

Конструктор фантастических существ: анатомия, экология, эволюция и личный каталог видов.

**Текущая версия:** 0.7.2 — офлайн-прототип на русском языке.

## Возможности
- **v0.7.2 — анатомические силуэты:** отдельная процедура прорисовки реальных форм головы (включая выразительную морду драконида, заострённый подбородок феи, череп инопланетянина), шеи и различного по ширине корпуса. Суставные руки, кисти с пальцами или когтями, двусоставные ноги, копыта/ласты, крупные крылья со строением перепонок и перьев, хвосты с деталями. Формы реагируют на исходную расу, параметры анатомии и набор органов. Доступны передняя, боковая и задняя проекции.
- Сцены, графические детали v0.7.1, пользовательские виды, сохранения и генетика v0.7 продолжают работать; процедура `web/anatomy_shapes_v072.js` автоматически встраивается в офлайн-APK.
- Данная версия по-прежнему отдельно устанавливаемая debug-сборка; экспорт JSON рекомендуется делать перед переносом коллекции.

- **v0.7.1:** серьёзная доработка векторной анатомии: многослойные тени тела и лица, контур глаз и строение рта, продольные детали плавников, отдельные жилки крыльев, дополнительные ряды чешуи и бронепластин, суставные линии, древесная фактура, подсветка особых органов. Детали генерируются по параметрам существа, не являются статичными иллюстрациями.
- Регулятор детализации 0–100% и переключатель «Сравнить» доступны на экране существа. Настройка сохраняется с каждым видом, экспортируется в PNG/SVG и включена в JSON-каталог без потери старых данных. Веб-плагин `web/anatomy_detail_v071.js` встраивается автономно в Android при сборке.
- Все механики v0.7, коллекция, родословные и оформление остаются. Устанавливается отдельно от v0.7 для сохранности старой коллекции из-за временной debug-подписи.

- **v0.7.0:** генетическая лаборатория с выбором двух сохранённых родителей, смешиванием анатомических признаков и окраски, вероятностью случайной мутации 0–30%, автоматическим сохранением потомства и родословной. Данные происхождения экспортируются в JSON v7.
- Гибриды разных исходных рас сохраняются как авторские виды, наследуя выбранные части тела. Старые каталоги по-прежнему импортируются.
- Начиная с этой версии в браузере генетика загружается из `web/genetics_v07.js`, а Android workflow встраивает этот скрипт в автономный HTML.
- Модель наследования упрощённая игровая и не моделирует реальную популяционную генетику. Для установки v0.7 используется отдельный debug package ID; перед удалением старой версии нужно экспортировать каталог в JSON.

- **v0.6.0:** добавлена шестая категория «Новый вид»: авторский организм без обязательной исходной расы. Пять выбираемых базовых морфологий: прямоходящая, водная, крылатая, змеевидная и четырёхрукая. После выбора можно независимо менять все ранее существующие детали тела, окраску, органы и среду.
- У нового вида настраиваются питание, передвижение, размножение, разумность, продолжительность жизни. Эти поля отображаются в биологическом досье и сохраняются вместе с анатомией при экспорте/импорте JSON v6.
- **Совместимость:** импорт каталогов v0.3–v0.5.5, хранение старых видов без изменения их морфологии. Новый APK использует отдельный Android package, чтобы оставлять старую версию и переносить коллекцию через JSON.
- **Ограничения:** эволюция пока прежняя, игровая модель; полноценная генетика, наследование и симуляция популяций ещё не включены. Подпись по-прежнему отладочная (без постоянного release-ключа).

- **v0.5.5 — выбранная иконка:** значок в виде открытого атласа и пяти рас (волк, лесной дух, драконид, русалка, фея), основанный на утверждённой иллюстрации. Добавлены обычная и адаптивная иконки Android, а также фирменный значок в шапке Android-приложения. Базовые механики и интерфейс v0.5.4 не менялись.
- v0.5.5 устанавливается рядом с v0.5.4 из-за временных debug-ключей подписи. Для переноса каталога необходим экспорт и импорт JSON.

- **v0.5.4 — иллюстрированный бестиарий:** вместо минималистичного интерфейса — богатое декоративное оформление с золотыми гравированными рамками, завитками и растительными орнаментами, выразительной типографикой, атмосферной сценой и декоративными элементами на панелях. Три темы: «Морская сокровищница», «Аметистовая магия», «Лесной фолиант».
- Новое оформление реализовано CSS и SVG без готовых картинок существ. Настройки, сохранение и экспорт существ остаются прежними. Новая версия устанавливается рядом с v0.5.3; переносить коллекцию можно через экспорт/импорт JSON.

- **v0.5.3 — новый интерфейс:** тёмная морская и аметистовая темы, адаптивная компоновка, нижняя навигация в Android, крупная панель существа, сгруппированные в раскрывающиеся разделы настройки анатомии, компактные действия и улучшенный контраст. Существ по-прежнему можно изменять прямо в редакторе; изображения не заменяют модели.
- Все изменения интерфейса локальные: без внешних библиотек и подключения к сети. Настройки раскрытых разделов и цветовая тема сохраняются локально.

- **v0.5.2:** возвращены полностью редактируемые SVG-модели вместо вставленных WebP-картинок. Добавлены процедурные слои чешуи, костных пластин, жабр, кожи, крыльев и плавников, световые акценты и объёмные градиенты. Все 5 рас и 15 подвидов имеют три ракурса, настройки анатомии мгновенно меняют рисунок.
- Два режима просмотра — «Модель» и «Атласный вид» — оба рисуются в SVG, без готовых статических фотографий. Сохранены энциклопедия и экспорт PNG/SVG/JSON.
- Новая Android-версия устанавливается отдельно под package `com.atlas.mirov.v52`. Для переноса существ из 0.5.1 экспортируйте коллекцию в JSON и импортируйте его в 0.5.2.

- **v0.5.1**: три локальные WebP-иллюстрации русалок (рифовая, глубинная, лагунная), галерея с миниатюрами и выбором подвида, связь с энциклопедией, просмотр без сети, экспорт изображения PNG 1100×1540. Иллюстрации адаптированы из предыдущих художественных концептов; изображения не генерируются заново при изменении анатомических параметров.
- Выпуск 0.5.1 включал три WebP; в 0.5.2 фотографии больше не загружаются, Android отображает только SVG-модели.

- **v0.5**: отдельный режим художественного векторного листа, с тематическими экологическими фонами, плюс новая энциклопедия с 15 досье (рацион, продолжительность жизни, размножение, коммуникация, социальные привычки, экология и происхождение).
- Сохранение текстового досье TXT и экспорт JSON версии 5; остались PNG и SVG, анатомический редактор, мобильный интерфейс.
- Редактор и лист иллюстрации разделены: художественное оформление не является фотореалистичным или полноценным 3D-рендером и не передаёт все детальные настройки как физическую модель.

- **v0.4**: самостоятельный многослойный SVG-рендерер с передней, боковой и задней проекциями, 13 новыми настройками головы, конечностей и рельефа кожи, новым биологическим анализом, увеличением до 180% и прозрачным PNG 2480×3120.
- Сохранение параметров анатомии в JSON v4, импорт коллекций прошлых версий.

- Пять исходных типов существ: русалки, феи, инопланетяне, дракониды и лесные духи.
- Для каждой расы три экологических подвида, 15 отдельных визуальных форм, индивидуальные детали тела и тематические фоны.
- Переключатель фона и полевой журнал с описанием адаптаций.
- Редактор внешности: голова (5 форм), глаза (1/2/4), четыре варианта хвоста, три типа крыльев, 0/2/4 конечности, пять текстур кожи и дополнительный цвет.

- Автоматическое локальное сохранение текущего черновика.
- Шесть сред обитания, условная оценка биологической пригодности и текстовые предупреждения о несовместимых особенностях.

- Локальная коллекция, импорт и экспорт JSON, экспорт изображений SVG/PNG.

## Перенос коллекции из v0.1 и v0.2
В первоначальной версии 0.1.1 использовалась временная debug-подпись, поэтому APK новой сборки нельзя безопасно ставить поверх неё. Версии 0.2–0.5.1 используют разные package ID (`com.atlas.mirov.v2`, `.v3`, `.v4`, `.v5`, `.v51`), чтобы debug-сборки с временной подписью могли быть установлены параллельно. В новой версии импортируйте JSON-каталог из старой перед её удалением. Откройте старую версию, выберите **Экспорт каталога**, затем в новой версии выберите **Импорт JSON** и укажите полученный файл. Старые записи дополняются начальными настройками новых анатомических полей и подвидов. Сохранение данных между будущими debug-APK с временными подписями пока не гарантировано; перед переустановкой всегда экспортируйте коллекцию.

## Android APK
Workflow **Android APK** в разделе [Actions](../../actions) собирает debug APK для Android. Скачайте ZIP-артефакт `atlas-mirov-debug-apk` из успешного запуска и установите APK на телефон. Это отладочная сборка; для публикации в Google Play потребуется release-подпись.

## Запуск в браузере
После распаковки `web/index.html` файл открывается в браузере и работает офлайн. Приложение не передаёт коллекцию существ на сервер.

## Ограничения
Изображения существ пока стилизованные векторные иллюстрации, а не фотореалистичный или 3D-редактор. Биологическая модель игровая и не претендует на научную точность.

## Структура проекта
- `web/index.html` — автономное браузерное приложение;
- `android/` — минимальная Android-оболочка с WebView и системным экспортом файлов;
- `.github/workflows/android.yml` — сборка установочного APK.

### Подпись APK
Автоматическая сборка GitHub Actions сейчас использует **отладочную подпись**, которая может меняться от сборки к сборке. Обновление поверх другой debug-сборки может не установиться; резервное копирование через JSON обязательно. Для безопасного обновления одним APK без смены package ID нужна постоянная приватная подпись release в GitHub Actions Secrets. Приватный ключ **не следует хранить в публичном репозитории**.

### Данные
Веб-версия и Android-версия используют разные локальные хранилища. Используйте экспорт JSON для переноса каталога между ними.
