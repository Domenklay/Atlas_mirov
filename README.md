# Атлас живых миров

Конструктор фантастических существ: анатомия, экология, эволюция и личный каталог видов.

**Текущая версия:** 0.4 — офлайн-прототип на русском языке.

## Возможности
- **v0.4**: самостоятельный многослойный SVG-рендерер с передней, боковой и задней проекциями, 13 новыми настройками головы, конечностей и рельефа кожи, новым биологическим анализом, увеличением до 180% и прозрачным PNG 2480×3120.
- Сохранение параметров анатомии в JSON v4, импорт коллекций прошлых версий.

- Пять исходных типов существ: русалки, феи, инопланетяне, дракониды и лесные духи.
- Для каждой расы три экологических подвида, 15 отдельных визуальных форм, индивидуальные детали тела и тематические фоны.
- Переключатель фона и полевой журнал с описанием адаптаций.
- Редактор внешности: голова (5 форм), глаза (1/2/4), четыре варианта хвоста, три типа крыльев, 0/2/4 конечности, пять текстур кожи и дополнительный цвет.
- Различимые SVG-иллюстрации, генерация PNG, адаптивный интерфейс с вкладками на телефоне.
- Автоматическое локальное сохранение текущего черновика.
- Шесть сред обитания, условная оценка биологической пригодности и текстовые предупреждения о несовместимых особенностях.
- Моделирование изменений между поколениями.
- Локальная коллекция, импорт и экспорт JSON, экспорт изображений SVG/PNG.

## Перенос коллекции из v0.1 и v0.2
В первоначальной версии 0.1.1 использовалась временная debug-подпись, поэтому APK новой сборки нельзя безопасно ставить поверх неё. Версии 0.2, 0.3 и 0.4 используют разные package ID (`com.atlas.mirov.v2`, `.v3`, `.v4`), чтобы debug-сборки с временной подписью не требовали удаления предыдущих приложений. Откройте старую версию, выберите **Экспорт каталога**, затем в новой версии выберите **Импорт JSON** и укажите полученный файл. Старые записи дополняются начальными настройками новых анатомических полей и подвидов. Сохранение данных между будущими debug-APK с временными подписями пока не гарантировано; перед переустановкой всегда экспортируйте коллекцию.

## Android APK
Workflow **Android APK** в разделе [Actions](../../actions) собирает debug APK для Android. Скачайте ZIP-артефакт `atlas-mirov-debug-apk` из успешного запуска и установите APK на телефон. Это отладочная сборка; для публикации в Google Play потребуется release-подпись.

## Запуск в браузере
После распаковки `web/index.html` файл открывается в браузере и работает офлайн. Приложение не передаёт коллекцию существ на сервер.

## Ограничения
Изображения существ пока стилизованные векторные иллюстрации, а не фотореалистичный или 3D-редактор. Биологическая модель игровая и не претендует на научную точность.

## Структура проекта
- `web/index.html` — автономное браузерное приложение;
- `android/` — минимальная Android-оболочка с WebView и системным экспортом файлов;
- `.github/workflows/android.yml` — сборка установочного APK.

### Подпись APK
Автоматическая сборка GitHub Actions сейчас использует **отладочную подпись**, которая может меняться от сборки к сборке. Обновление поверх другой debug-сборки может не установиться; резервное копирование через JSON обязательно. Для безопасного обновления одним APK без смены package ID нужна постоянная приватная подпись release в GitHub Actions Secrets. Приватный ключ **не следует хранить в публичном репозитории**.

### Данные
Веб-версия и Android-версия используют разные локальные хранилища. Используйте экспорт JSON для переноса каталога между ними.
